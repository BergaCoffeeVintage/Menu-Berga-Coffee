# Berga Coffee — Digital Menu

Website ini dibuat khusus untuk MENAMPILKAN desain menu Berga Coffee yang sudah dibuat.

## Isi
- 9 halaman menu dalam bentuk gambar
- Responsive untuk desktop dan HP
- Klik gambar untuk membuka mode fullscreen/lightbox
- Tombol panah untuk pindah halaman
- Keyboard: ← / → untuk pindah, Esc untuk menutup
- Tombol FULLSCREEN
- Tanpa framework dan tanpa internet dependency

## Cara menjalankan
1. Buka folder ini di Visual Studio Code.
2. Install extension "Live Server" jika belum ada.
3. Klik kanan `index.html`.
4. Pilih `Open with Live Server`.

Alternatif: cukup buka `index.html` langsung di browser.

## Mengganti desain
Ganti file di folder `assets/` dengan gambar baru, lalu sesuaikan nama file di `script.js` jika nama filenya berbeda.

Urutan halaman:
1. Toast & Oven Bakes / Sweet Endings

3. From Berga's Kitchen / Pasta Collection
4. Signature Non-Coffee / Coffee / Tea
5. Matcha / Choco / Frappe
